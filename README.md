# Юнит‑тестирование Stellar Burgers  
*(Дипломный проект)* Diplom_1


## Описание проекта


Проект содержит **юнит‑тесты** для программы заказа бургеров в сервисе *Stellar Burgers*.


**Цель:** обеспечить 100 % покрытие кода тестами с использованием моков, стабов и параметризации.

**Основной сайт:** [Stellar Burgers](https://stellar-burgers.example.com) 


## Задание


Протестировать функциональность программы, отвечающей за:
- создание бургера;
- расчёт стоимости заказа;
- формирование чека;
- управление ингредиентами (добавление/удаление).


**Требования:**
- покрыть тестами класс `Burger`;
- использовать **моки** для изоляции зависимостей;
- применить **параметризованные тесты** для проверки комбинаций ингредиентов и цен;
- достичь **100 % покрытия кода** (по отчёту JaCoCo).

## Реализованная функциональность


- Тестирование класса `Burger`.
- Проверка расчёта стоимости заказа (корректность суммы).
- Валидация формирования чека (формат и содержание).
- Управление ингредиентами:
  - добавление;
  - удаление;
  - проверка лимитов.
- Параметризованные тесты для различных сценариев (ингредиенты, цены).
- Использование моков и стабов для имитации зависимостей.


## Используемые технологии


- Java 11+;
- Maven 3.8+;
- JUnit 4.13.2;
- Mockito 5.3.1;
- JaCoCo 0.8.8;
- Hamcrest 2.2.


## Как запустить тесты и проверить покрытие кода


### 1. Запуск всех тестов

# Запуск всех тестов
mvn clean test

# Проверка покрытия кода
mvn jacoco:report

# Запуск с генерацией отчета о покрытии
mvn clean jacoco:prepare-agent test jacoco:report
